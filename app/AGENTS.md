# 요청과 화면 진입점

이 영역은 페이지, 레이아웃, 서버 작업과 HTTP 요청 처리를 소유한다. 재사용되는 데이터 접근, Markdown 규칙, 사용자 설정 모델과 데이터베이스 정의는 이 영역의 책임이 아니다.

- 페이지는 인증이 필요한 데이터에 접근하기 전에 소유자 검사를 호출하고, 그 결과의 사용자 ID를 모든 기능 조회에 전달한다.
- HTTP 진입점은 인증 실패를 리다이렉트하지 않고 상태 코드와 JSON으로 응답한다. 페이지용 인증 도우미를 API에서 재사용하지 않는다.
- 서버 작업과 HTTP 진입점은 입력을 검증하고 기능 계층을 호출한다. 같은 저장 쿼리나 제품 규칙을 여러 진입점에 복제하지 않는다.
- 서버 페이지는 같은 애플리케이션의 HTTP 주소를 다시 호출하지 않는다.
- 동적 문서 slug는 조회 전에 안전하게 디코딩하며 잘못된 인코딩은 404로 처리한다.
- 인증 콜백은 세션 쿠키를 최종 리다이렉트 응답 객체에 기록한다. 콜백 변경 후 새 로그인 링크에서 첫 화면까지 검증한다.
- 개인 데이터 API 테스트는 인증 없음, 다른 사용자, 잘못된 입력, 정상 소유자의 네 경우를 포함한다.
