# 사용자 인터페이스

이 영역은 브라우저 상호작용과 표현을 소유한다. 데이터베이스 쿼리, 권한 정책과 서버 비밀 처리는 이 영역의 책임이 아니다.

- 브라우저 상태가 필요한 구성 요소만 클라이언트로 만들고, 서버에서 준비할 수 있는 데이터 조회를 효과 훅으로 옮기지 않는다.
- Markdown 렌더링은 원시 HTML을 실행하지 않고, 인라인 코드와 코드 블록 안의 Wiki link 문법을 변환하지 않는다.
- 연결 탐색은 일반 링크 이동과 구분한다. 클릭 고정, Escape 닫기, 화면 경계, 최대 열 카드 3개, 키보드 접근을 함께 보존한다.
- 편집기의 로컬 임시 저장 키는 문서별로 분리하고, 서버 저장 성공 전에는 임시 내용을 삭제하지 않는다.
- 낙관적 설정 변경은 서버 실패 시 이전 값으로 되돌리고 오류를 사용자에게 보여준다.
- 테마 색상과 설정 화면의 대표색은 함께 갱신하되, 공통 모서리·간격·제목 형태를 테마별로 갈라놓지 않는다.
- 상호작용 테스트는 마우스뿐 아니라 키보드, 취소·실패, 새로고침 후 상태를 포함한다.
