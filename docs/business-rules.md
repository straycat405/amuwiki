# 제품 규칙

## 제품의 중심 경험

아무위키의 기본 지식 단위는 문서다. 제목과 별칭은 하나의 문서를 가리키는 개념 이름이며, 문단이나 블록은 현재 독립된 식별자나 수명주기를 갖지 않는다. 이 단위는 Obsidian에서 얻은 Markdown 소유권의 장점과, 발더스 게이트 3의 인게임 가이드처럼 현재 문맥을 잃지 않고 설명을 연쇄 탐색하는 경험을 결합한다.

사용자는 연결된 개념을 확인하기 위해 읽던 문서와 위치를 잃어서는 안 된다. 가리키기는 짧은 요약을 보여주고, 클릭은 화면 위에 탐색 가능한 카드로 고정하며, 전체 문서 열기를 명시적으로 선택했을 때만 현재 문서를 떠난다. 화면에는 고정 카드가 최대 세 개만 동시에 보이고 이전 탐색은 경로로 접힌다. 관련 문서 안에서 가리키기 미리보기를 다시 중첩하지 않고 클릭 탐색만 허용한다.

## 문서와 개념

- 문서 제목은 사용자 공간 안에서 정규화 후 하나만 존재해야 한다. 같은 정규화 제목이나 기존 별칭과 충돌하면 저장하지 않는다.
- 제목을 바꾸면 이전 제목을 같은 문서의 별칭으로 보존해 기존 Wiki link가 끊어지지 않게 한다. 다른 문서가 이미 그 이름을 소유하면 제목 변경을 완료하지 않는다.
- `[[문서]]`, `[[문서|표시명]]`, `[[문서#제목]]`은 원문에 보존된다. 존재하지 않는 대상도 평문으로 지우지 않고 끊긴 링크로 보여준다.
- 명시적 저장 때 문서 본문, 새 리비전, 링크 색인을 함께 반영한다. 셋 중 하나만 반영된 상태를 성공으로 취급하지 않는다.
- 입력 중 임시 저장은 서버 리비전을 만들지 않는다. 다른 서버 버전이 생긴 경우 자동 덮어쓰지 않고 충돌을 알려야 한다.

## 문서 상태

- `draft`는 새 문서 저장 전에 첨부 대상을 만들기 위한 숨김 상태다. 목록, 검색, 최근 문서에 노출하지 않는다.
- `active`는 정상적으로 읽고 편집할 수 있는 상태다.
- 휴지통 이동은 내용을 즉시 지우지 않고 `archived` 상태와 삭제 시각을 남긴다. 복원은 기존 내용을 되살리며, 버전 충돌이 있으면 덮어쓰지 않는다.
- 저장되지 않은 임시 문서와 참조를 잃은 첨부파일은 장기 보존 대상이 아니다. 정리 기능이 생기면 충분한 유예 시간과 소유권 검사를 거쳐 제거해야 하며, 현재처럼 무기한 남는 상태는 완성된 동작으로 간주하지 않는다.

## 검색과 최근 기록

검색 순서는 제목 완전 일치, 별칭 완전 일치, 제목·별칭 접두어, 제목·별칭 유사도, 본문 부분 일치, 최근 사용 가중치 순이다. 현재는 본문 검색이 구현되지 않았으므로 검색 결과가 본문까지 찾는다고 표시해서는 안 된다. 임시 문서와 휴지통 문서는 검색 결과에서 제외한다.

최근 검색어는 사용자가 결과를 확정해 이동하거나 검색 페이지를 연 시점에만 기록하며, 입력 중인 모든 글자를 기록하지 않는다. 최근 문서를 목록에서 숨기는 동작은 원본 문서를 삭제하지 않으며, 해당 문서를 다시 열면 최근 목록에 다시 나타난다.

## 개인 주석

주석은 협업 댓글이 아니라 문서의 특정 텍스트 범위에 사용자가 붙이는 개인 메모다. 선택 위치와 함께 선택 원문, 앞뒤 문맥, 작성 당시 문서 버전을 저장한다. 문서가 바뀌면 정확한 원문, 앞뒤 문맥, 기존 위치와 가까운 순서로 다시 연결하며, 한 대상을 확정할 수 없으면 임의 위치에 붙이지 않고 원문을 보존한 `orphaned` 상태로 둔다. 사용자는 연결이 끊긴 주석을 새 범위에 다시 지정할 수 있어야 한다.

같은 범위에 여러 주석을 둘 수 있지만 겹친 표시는 하나의 묶음으로 보여준다. 해결 처리는 주석을 지우는 동작이 아니며 다시 찾을 수 있어야 한다. 주석 삭제와 문서 삭제는 즉시 물리 삭제하지 않고, 문서를 복원할 때 주석을 자동 삭제하거나 새로 만들지 않는다.

## 가져오기와 내보내기

가져오기는 원본을 저장하는 분석 단계와 사용자가 충돌 정책을 확인한 뒤 문서를 만드는 확정 단계로 나뉜다. 분석만으로 사용자 문서를 만들거나 기존 문서를 변경해서는 안 된다. 충돌 기본값은 건너뛰기이며, 이름 바꾸기는 안전한 숫자 접미사를 사용한다. 기존 문서 자동 덮어쓰기와 병합은 현재 제공하지 않는다.

YAML의 제목과 별칭은 알려진 필드로 옮기고, 알 수 없는 frontmatter는 손실 없이 보존해야 한다. 현재 가져오기 구현은 제목과 별칭만 옮기고 나머지 frontmatter를 새 문서에 기록하지 못하므로 이 규칙을 아직 충족하지 않는다. 해석할 수 없는 Wiki link와 지원하지 않는 문법도 가능한 한 원문과 경고를 남긴다. 운영 중 원본은 데이터베이스지만, 사용자는 서비스가 없어져도 읽을 수 있도록 Markdown, frontmatter, 별칭, 시각 정보와 첨부파일 전체를 내보낼 수 있어야 한다. 로컬 폴더와의 지속적인 양방향 동기화는 이식 가능성의 필수 조건이 아니다.

## 공개와 서비스 확장

현재 사용자는 한 명이지만 사용자 데이터 모델은 각 사용자가 독립된 공간을 갖는 서비스를 전제로 한다. 가입 개방은 현재 개인 사용 경험을 검증한 뒤 진행한다. 공개 공유나 게시 기능이 추가되더라도 기존 문서는 자동 공개되지 않으며, 사용자가 선택한 문서와 공개 범위만 외부에 노출된다.
