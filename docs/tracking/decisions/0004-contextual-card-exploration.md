# 현재 문맥 안의 카드 탐색

## 배경

일반 Wiki link는 추가 설명을 확인할 때 현재 문서와 읽던 위치를 떠나게 한다. 발더스 게이트 3의 인게임 가이드처럼 낯선 개념을 현재 화면 안에서 이어서 확인할 수 있는 경험이 제품의 차별점이다.

## 결정

가리키기는 짧은 정보를 일시적으로 보여주고, 클릭은 상호작용 가능한 카드로 고정한다. 카드 안의 연결 개념은 새 카드로 열며, 사용자가 전체 문서 열기를 선택했을 때만 현재 문서로부터 이동한다. 동시에 보이는 고정 카드는 세 개로 제한하고 이전 단계는 탐색 경로로 보존한다.

## 검토한 대안

- 모든 링크를 즉시 새 페이지로 여는 방식은 구현이 단순하지만 현재 문맥을 보존하지 못해 선택하지 않았다.
- 무제한 중첩 팝업은 탐색 깊이를 보존하지만 작은 화면과 접근성에서 제어하기 어렵고 화면을 빠르게 가려 선택하지 않았다.
- 별도 그래프 화면은 전체 관계를 보여주지만 읽는 순간의 질문에 답하는 흐름과 달라 핵심 탐색 방식으로 선택하지 않았다.

## 결과

연결 기능은 페이지 이동 수를 늘리는 것보다 문맥 보존을 우선한다. 카드 수 제한, 닫기, 키보드와 모바일 대체 조작은 시각 효과가 아니라 기능 계약이다.
