# 현재 개발 상태

기준 커밋은 `2112247`이며 2026-09-15에 현재 작업 트리에서 단위 테스트 69개, 타입 검사, lint, 프로덕션 빌드를 실행했다. 모두 종료 코드 0으로 통과했고 lint에는 Markdown 이미지 렌더링의 `<img>` 사용에 관한 기존 경고 2개가 남아 있다. SQL 권한 검사와 브라우저 전 과정은 이번 확인에서 다시 실행하지 않았으며, 과거 수동 검증 기록만 존재한다.

## 이번 작업에서 자동 검사됨

- 문서·인증·검색·가져오기·설정·UI를 다루는 Vitest 테스트 69개
- Next.js 경로 타입 생성과 TypeScript 검사
- ESLint 전체 검사: 오류 0개, 기존 이미지 경고 2개
- Next.js 프로덕션 빌드와 현재 경로 생성

## 구현됨·이번에는 통합 검사를 다시 실행하지 않음

- 소유자 이메일 한 명을 허용하는 매직 링크 로그인과 안전한 콜백 경로
- 사용자 ID 기반 스키마와 주요 테이블·Storage의 행 단위 권한 정책
- 문서 생성·수정, 명시적 저장, 리비전, 버전 충돌, 휴지통 이동·복원
- 제목·별칭, 명시적 Wiki link, 백링크와 한글 문서 주소
- Markdown 렌더링, 원시 HTML 차단, 외부 링크 보호, 줄바꿈 선택
- 호버 미리보기, 클릭 고정 카드, 카드 안 연결 탐색, 이미지 확대 보기
- 제목·별칭 검색, 최근 검색어, 실제 열람 기반 최근 문서
- 이미지 업로드·붙여넣기, 비공개 다운로드, 내용 해시 기반 중복 제거
- `.md`, `.markdown`, `.txt` 다중 파일 분석·미리보기·가져오기와 충돌 시 건너뛰기·이름 바꾸기
- 테마·명암·글꼴·크기·본문 폭·미리보기 설정과 새로고침 후 유지

이 목록에는 단위 테스트가 포함된 기능도 있지만, 로컬 Supabase SQL 검사와 로그인부터 저장·가져오기까지의 브라우저 전 과정은 과거 기록만 있고 이번 작업에서는 다시 실행하지 않았다.

## 남은 작업 순서

1. 문서 텍스트 범위에 붙는 개인 주석: 생성·수정·해결, 편집 후 앵커 복구, 연결이 끊긴 주석 재지정.
2. 본문 부분 일치 검색: 기존 제목·별칭 우선순위를 유지하면서 한글 문서 규모별 성능을 검증.
3. 저장되지 않은 임시 문서와 참조를 잃은 첨부파일 정리: 유예 기간, 소유권, DB 행과 Storage 객체의 일관된 삭제를 포함.
4. ZIP·Obsidian vault 가져오기: 경로 이탈·심볼릭 링크·압축 폭탄 방어, 상대 경로 링크와 첨부 이전, 묶음 전체 링크 재색인.
5. 가져오기 원본 보존 보완: 현재 제목·별칭 외 frontmatter가 새 문서에 저장되지 않는 문제를 고치고 알 수 없는 YAML 필드의 왕복을 검증.
6. 전체 내보내기: Markdown, frontmatter, 별칭, 생성·수정 시각, 첨부파일과 체크섬을 읽을 수 있는 ZIP으로 제공하고 빈 환경 복원을 검증.

## 후속 범위

- 모바일에서 카드 탐색과 주석을 동일하게 사용할 수 있는 하단 시트·키보드·스크린리더 경험
- 가져오기 부분 실패 재시도, 정기 백업과 복원 리허설, 감사 기록과 운영 알림
- 개인 사용 경험 검증 후 일반 가입·계정 복구·탈퇴·악용 방지를 포함한 다중 사용자 서비스 전환
- 사용자가 선택한 문서를 명시적으로 공유하거나 게시하는 기능
- 서비스 운영비, 배치 작업, 백업과 사용자 증가를 함께 고려한 배포 대상 결정

협업 편집, 추천 피드, AI 요약·자동 태깅, 그래프 화면, 플러그인 생태계는 핵심 기록·탐색·이식 경험이 검증된 뒤 평가한다.
