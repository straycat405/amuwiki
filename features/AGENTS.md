# 기능과 데이터 접근

이 영역은 문서, 검색, 최근 기록, 설정, 첨부와 가져오기의 타입·검증·데이터 접근을 소유한다. 페이지 렌더링과 HTTP 응답 형식, 공통 외부 클라이언트 생성은 이 영역의 책임이 아니다.

- 모든 사용자 데이터 함수는 호출자가 전달한 사용자 ID로 조회 범위를 제한하거나 사용자 세션을 사용하는 권한 검증 함수를 호출한다.
- 문서 생성·수정은 공통 저장 경로를 사용해 제목 충돌, 리비전과 링크 색인 규칙을 우회하지 않는다.
- 상태 변경 결과는 충돌, 중복, 찾을 수 없음과 알 수 없는 실패를 구분해 진입점이 사용자 메시지로 바꿀 수 있게 한다.
- 가져오기 파서는 원문 보존을 우선한다. 알려진 제목·별칭만 해석하고, 알 수 없는 frontmatter와 지원하지 않는 내용을 임의로 버리지 않는다.
- Storage 객체 키용 인코딩과 화면에 보여줄 원래 파일 경로를 섞지 않는다. 한글 파일명 왕복 테스트를 유지한다.
- 검색·최근 기록은 임시 문서와 휴지통 문서를 결과에 노출하지 않는다.
- 데이터 함수 테스트는 정상 결과뿐 아니라 빈 결과, 외부 오류, 사용자 범위와 중복·충돌을 검증한다.
