# 공통 경계와 변환

이 영역은 환경값 검증, 인증 보조, Supabase 클라이언트 구성, Markdown·Wiki link·slug 변환을 소유한다. 제품 화면, 특정 페이지의 응답과 기능별 데이터 쿼리는 이 영역의 책임이 아니다.

- 공개 환경값과 서버 전용 환경값을 분리하고, 서버 전용 값이 브라우저에서 호출 가능한 함수의 반환값에 들어가지 않게 한다.
- 서버와 브라우저의 Supabase 클라이언트는 각각의 쿠키·세션 수명주기에 맞는 생성 함수를 사용한다.
- 사용자 이메일과 개념 이름의 정규화는 저장·검색·비교에서 같은 함수를 사용한다. 호출 위치마다 다른 소문자·공백 규칙을 만들지 않는다.
- Wiki link 파서는 원문 위치와 표시명을 보존하고 코드 영역을 변경하지 않는다. 존재하지 않는 대상은 삭제하지 않고 끊긴 상태로 렌더링할 수 있게 한다.
- 한글 slug 디코딩은 예외를 외부로 던지지 않으며 잘못된 입력을 명시적인 실패값으로 반환한다.
- 공통 변환을 바꾸면 한글, 유니코드 정규화, 빈 값, 잘못된 인코딩과 코드 블록 회귀를 테스트한다.
