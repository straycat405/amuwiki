# 데이터와 권한

이 영역은 관계형 스키마, 데이터베이스 함수, 행 단위 권한, 비공개 Storage 정책과 SQL 검증을 소유한다. 화면 상태와 사용자 메시지, 브라우저 렌더링은 이 영역의 책임이 아니다.

- 모든 변경은 기존 파일 수정이 아닌 새 순번 마이그레이션으로 추가한다. 이미 배포된 함수 변경도 새 파일에서 `create or replace` 또는 명시적인 교체로 수행한다.
- 사용자 소유 테이블은 사용자 ID를 기준으로 행 단위 권한을 활성화하고, 참조 테이블도 상위 소유자 관계를 통해 다른 사용자 데이터를 차단한다.
- 데이터베이스 함수는 호출자 권한으로 실행하며 필요한 `search_path`를 명시한다. 확장 연산자 때문에 `public`이 필요한 검색 함수 외에는 빈 경로를 우선한다.
- 문서 저장 함수는 예상 버전을 확인한 뒤 문서, 리비전과 링크 색인을 한 트랜잭션에서 처리한다.
- 파일 정책은 객체 경로 첫 부분의 사용자 ID와 인증 사용자 ID가 일치할 때만 읽기·쓰기를 허용한다.
- 스키마 변경 후에는 빈 데이터베이스 적용과 기존 데이터 보존 적용을 모두 고려하고, 행 단위 권한·문서 CRUD·수명주기·Wiki link SQL 검사를 실행한다.
- 데이터가 있는 로컬 또는 원격 환경에 초기화 명령을 실행하지 않는다.
